#  Loan Default Prediction & Risk Analysis Dashboard

##  Overview

This project focuses on analyzing and understanding **loan default behavior** using financial and demographic data.

It combines **Python-based data analysis** with an **interactive Power BI dashboard** to uncover patterns in:

* Loan defaults
* Credit risk factors
* Borrower demographics
* Financial trends

---

## Objective

The main objectives of this project are to:

* Analyze factors influencing loan default
* Identify high-risk borrower segments
* Understand financial behavior across different demographics
* Support data-driven decision-making for risk management

---

##  Tech Stack

* **Python** (Data Analysis & Preprocessing)
* **Jupyter Notebook** (`loan-default-prediction.ipynb`)
* **Power BI** (`LOAN DEFAULT.pbix`)
* **Dataset**: Loan Default / Credit Risk Dataset

---

##  Key Features

###  Loan Default Overview

* Default rate trends over years
* Default rate across employment types
* Loan distribution by purpose (Home, Business, Education, etc.)

---

###  Applicant Demographics & Financial Profile

* Credit score segmentation (Low, Medium, High, Very Low)
* Loan amount distribution across age groups
* Impact of marital status and education
* Loan distribution based on mortgage and dependents

---

###  Financial Risk Metrics

* Total loan amount and average loan size
* Average credit score and debt-to-income (DTI) ratio
* Year-over-year loan growth and default trends
* Income segmentation and employment analysis

---

##  Workflow

1. Data collection from loan dataset
2. Data cleaning and preprocessing in Python
3. Exploratory Data Analysis (EDA)
4. Feature engineering and transformation
5. Dashboard creation in Power BI

---

##  Key Insights

* Default rates vary significantly across employment types
* Credit score plays a critical role in loan risk assessment
* Income and DTI ratio are strong indicators of repayment capability
* Certain demographic groups show higher default tendencies
